# 💰 Daily Expense Tracker

A responsive and user-friendly web application for tracking daily expenses, managing monthly budgets, and analyzing spending patterns.

## 🌐 Live Demo

https://sshashikanth080-cyber.github.io/daily-expense-tracker/

## ✨ Features

- ➕ Add new expenses
- ✏️ Edit and update expenses
- 🗑️ Delete expenses
- 💰 Track total expenses
- 📅 View today's expenses
- 📊 View monthly expenses
- 💵 Set and manage monthly budget
- 📈 Track remaining budget and budget usage
- 🥧 Category-wise spending chart
- 🔍 Search expenses
- 🏷️ Filter by category
- 📅 Filter by date
- 📋 Generate monthly reports
- 📥 Export expenses to CSV
- 📄 Export expenses to PDF
- 🌙 Dark Mode
- 💾 Data stored using browser LocalStorage
- 📱 Mobile responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- jsPDF
- LocalStorage

## 📁 Project Structure

- `index.html` — Main application structure
- `style.css` — Styling and responsive design
- `script.js` — Application logic and functionality
